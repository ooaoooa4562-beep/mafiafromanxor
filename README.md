# Mafia from Anxor

Браузерная онлайн-мафия: Django backend и адаптивный игровой интерфейс.

## Сейчас в проекте

- `frontend/index.html` — первый адаптивный lobby UI: создание комнаты, ввод кода, профиль в localStorage, список демонстрационных столов и проверка доступа к микрофону.
- `backend/` — Django-проект с приложениями аккаунтов, друзей, комнат, игры и голоса.
- `GET/POST /api/rooms/` — список публичных ожидающих комнат и создание комнаты (требует авторизованную Django-сессию).
- `POST /api/rooms/<uuid>/join/` — вступление в комнату (требует авторизованную Django-сессию).
- Владелец автоматически добавляется в состав комнаты; повторное вступление не создаёт дубликат. Приватные комнаты не попадают в публичный список.
- Настройки Django читают секреты и параметры окружения; Redis channel layer включается через `REDIS_URL`.

> Важно: текущий lobby — клиентский прототип. Создание/вход в комнату пока не синхронизируются с сервером и не создают реальную игровую сессию. Проверка микрофона только запрашивает локальное разрешение браузера; удалённого голосового чата пока нет.

## Запуск интерфейса

Откройте `frontend/index.html` в браузере или запустите локальный статический сервер из корня:

```bash
python -m http.server 8080
```

Затем откройте http://localhost:8080/frontend/ . Для проверки микрофона используйте localhost или HTTPS.

## Запуск Django backend

1. Создайте виртуальное окружение и установите зависимости проекта.
2. Скопируйте `backend/.env.example` в локальное окружение (не коммитьте реальные значения).
3. Установите `DJANGO_SECRET_KEY` и остальные переменные из примера.
4. Из каталога `backend` выполните миграции и запустите сервер:

```bash
python manage.py migrate
python manage.py runserver
```

Для production установите `DJANGO_DEBUG=false`, задайте уникальный `DJANGO_SECRET_KEY`, корректный `DJANGO_ALLOWED_HOSTS` и Redis. Для Redis channel layer нужен пакет `channels-redis`.

## План реализации

1. API аккаунтов, профилей и друзей.
2. Комнаты, приглашения и WebSocket-события через Django Channels.
3. Серверная машина состояний матча: роли, ночь/день, таймеры, голосование и победа.
4. WebRTC signaling и голосовые каналы с проверкой прав на сервере; для масштабирования — SFU.
5. История матчей, статистика, рейтинг, модерация и тесты.

## Безопасность

Секретный ключ больше не хранится в settings.py. Если старый ключ уже был опубликован в GitHub, считайте его скомпрометированным: задайте новый `DJANGO_SECRET_KEY` в окружении и завершите активные сессии при переходе на новый ключ. Не коммитьте `.env`, SQLite-базу или Python cache.
