# Mafia UI

Статический адаптивный прототип интерфейса. Откройте `index.html` или запустите сервер из корня репозитория: `python -m http.server 8080`. Затем перейдите на `/frontend/`.

Комнаты, чат и игровые фазы в этой версии демонстрационные и локальные. Кнопка микрофона проверяет доступ к микрофону браузера, но не транслирует аудио. Реальный multiplayer и WebRTC подключаются через backend следующим этапом.
