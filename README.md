# Mafia from Anxor

Браузерная онлайн-мафия: Django backend, игровые комнаты, роли, игровые фазы, друзья и WebRTC signaling.

## Быстрый запуск в интернете без локального терминала

Проект подготовлен для Render Blueprint:

1. Открой https://dashboard.render.com/blueprints.
2. Войди через GitHub и разреши Render доступ к репозиторию `ooaoooa4562-beep/mafiafromanxor`.
3. Нажми **New Blueprint Instance**, выбери репозиторий и ветку `main` (после слияния PR с настройкой деплоя).
4. Render прочитает `render.yaml`, создаст веб-сервис, PostgreSQL и Redis. Проверь показанные тарифы и условия бесплатного плана, затем нажми **Apply**.
5. Дождись статуса **Live** и открой адрес сервиса вида `https://mafia-from-anxor.onrender.com`.

Render сам установит зависимости, соберёт static files, применит миграции и запустит ASGI-сервер Daphne. Команды вводить на своём компьютере не нужно.

**Важно о тарифах:** Blueprint использует бесплатные планы Render для первого теста. Бесплатный веб-сервис может засыпать после бездействия, а бесплатная PostgreSQL-база имеет ограниченный срок жизни (обычно 30 дней). Перед реальным запуском с игроками проверь актуальные условия Render и перейди на платные постоянные ресурсы, если хочешь сохранить аккаунты и матчи. Не храни важные данные в бесплатной тестовой базе.

## Возможности

- Регистрация, вход и сессионная авторизация.
- Создание комнат и вход по коду.
- Серверная раздача ролей: мафия, доктор, комиссар, мирные.
- Ночь, день, голосование, игровые таймеры и условия победы.
- Друзья, заявки и статистика.
- WebSocket-события комнаты и WebRTC signaling.
- Django admin для управления данными.

## Локальная разработка

Установка и запуск через Python описаны ниже только для разработчиков. Для обычного запуска на Render локальный терминал не нужен.

```bash
pip install -r requirements.txt
cd backend
python manage.py migrate
python manage.py runserver
```

## Голосовой чат и TURN

Голос использует WebRTC с P2P-соединениями, а сигнальные сообщения передаются через WebSocket. Для надёжной связи между разными сетями и мобильными операторами настрой TURN-сервер (например, coturn или управляемый TURN-провайдер). Добавь в переменные окружения Render `MAFIA_ICE_SERVERS` как JSON-массив ICE-серверов, например:

```json
[{"urls":"stun:stun.l.google.com:19302"},{"urls":"turn:turn.example.com:3478","username":"TURN_USERNAME","credential":"TURN_CREDENTIAL"}]
```

Используй реальные TURN-учётные данные своего провайдера и не публикуй их в репозитории. Если `MAFIA_ICE_SERVERS` не задан, игра использует публичный STUN: этого может быть недостаточно за строгим NAT/firewall. Для больших комнат вместо P2P mesh понадобится SFU (например, LiveKit/mediasoup).

## Перед постоянным production-запуском

- Перейти на платные постоянные PostgreSQL и Redis, настроить резервные копии.
- Добавить постоянное хранилище для загружаемых аватаров (сейчас локальные media-файлы не гарантированно сохраняются между пересборками).
- Настроить TURN/SFU для голоса, мониторинг, модерацию и rate limiting.
- Проверить CI, регистрацию, создание комнат, полную игру и WebRTC с несколькими устройствами.
